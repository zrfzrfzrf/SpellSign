Element icons for the element ring (ElementWheel) in the tutorial and beside the dragon's health bar.

Put a PNG here to replace an element's drawn icon. The file name must be exactly:
  Water.png
  Fire.png
  Lightning.png

Square, transparent background, about 256x256. The picture is used as the whole icon,
so include any background badge you want in the image itself. An element without a
PNG keeps the drawn icon (a white symbol on a badge in the element's color).
